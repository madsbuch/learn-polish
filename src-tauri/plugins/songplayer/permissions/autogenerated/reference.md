## Default Permission

Everything the app's song player uses.

#### This default permission set includes the following:

- `allow-set-queue`
- `allow-play`
- `allow-pause`
- `allow-toggle`
- `allow-next`
- `allow-previous`
- `allow-seek-to`
- `allow-skip-to`
- `allow-set-repeat`
- `allow-stop`
- `allow-get-state`
- `allow-remote-start`
- `allow-remote-stop`
- `allow-multicast`
- `allow-register-listener`
- `allow-remove-listener`
